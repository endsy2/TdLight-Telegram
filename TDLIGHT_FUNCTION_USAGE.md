## Functionality Details

### TDLib API (TdApi.*)

- AddChatMember: Adds a user to a chat or group.
- AddChatToList: Moves a chat to a specific list (main/archive/custom list).
- BlockListMain: Represents the main block list target used for blocking operations.
- CancelDownloadFile: Cancels an active file download.
- ChatAdministratorRights: Defines administrator permissions in a chat/supergroup.
- ChatListArchive: Represents the archive chat list.
- ChatListMain: Represents the main/default chat list.
- ChatMemberStatusAdministrator: Assigns administrator status to a member.
- ChatMemberStatusBanned: Sets banned status (cannot participate).
- ChatMemberStatusLeft: Sets status as left/removed from chat.
- ChatMemberStatusMember: Sets normal member status.
- ChatMemberStatusRestricted: Restricts member permissions with specific rules.
- ChatPermissions: Defines allowed actions in a chat (send media, messages, etc.).
- CheckAuthenticationCode: Verifies login code during authentication.
- CheckAuthenticationPassword: Verifies 2FA password during authentication.
- CloseChat: Closes a chat context in TDLib.
- CreateChatInviteLink: Creates a new invite link for a chat.
- DeleteChatHistory: Deletes chat message history.
- DownloadFile: Starts or controls file download from Telegram servers.
- FormattedText: Stores text with formatting entities.
- GetBasicGroup: Gets basic group metadata by group id.
- GetBasicGroupFullInfo: Gets extended basic group information.
- GetBlockedMessageSenders: Returns blocked users/senders.
- GetChat: Gets chat object/details by chat id.
- GetChatHistory: Retrieves chat messages with pagination parameters.
- GetChatInviteLinks: Lists invite links for a chat.
- GetChatPinnedMessage: Retrieves currently pinned message in a chat.
- GetChats: Retrieves chat ids from a chat list with limit/options.
- GetGroupCallStreams: Retrieves active stream info for a group call.
- GetMessage: Retrieves one message by chat id and message id.
- GetMessageLink: Generates or retrieves a shareable message link.
- GetSupergroup: Gets supergroup metadata.
- GetSupergroupFullInfo: Gets extended supergroup info.
- GetSupergroupMembers: Retrieves members of a supergroup with filters.
- GetUser: Gets user profile data by user id.
- GetUserProfilePhotos: Retrieves user profile photos list.
- InputChatPhotoStatic: Represents a static photo used as chat photo input.
- InputFileLocal: References a local file for upload.
- InputMessageAudio: Input content type for sending audio.
- InputMessageDocument: Input content type for sending documents/files.
- InputMessagePhoto: Input content type for sending photos.
- InputMessageReplyToMessage: Sets message reply target by message id.
- InputMessageText: Input content type for sending text messages.
- InputMessageVideo: Input content type for sending video.
- InputMessageVoiceNote: Input content type for sending voice notes.
- JoinChatByInviteLink: Joins a chat using an invite link.
- LeaveChat: Leaves a chat/group/channel.
- MessageSendOptions: Configures send behavior (silent, scheduling, etc.).
- MessageSenderUser: Identifies a user as a message sender target.
- OpenChat: Opens chat context (can affect read/open state and updates).
- PhoneNumberAuthenticationSettings: Configures phone login behavior.
- PinChatMessage: Pins a message in a chat.
- RevokeChatInviteLink: Revokes an existing invite link.
- SearchChats: Searches chats by query.
- SearchPublicChat: Searches public chat by username/title.
- SendMessage: Sends message content to a chat.
- SetAuthenticationPhoneNumber: Submits phone number for login flow.
- SetChatDescription: Updates chat description/about text.
- SetChatMemberStatus: Changes role/status of a chat member.
- SetChatPhoto: Updates chat photo.
- SetChatTitle: Updates chat title.
- SetMessageSenderBlockList: Adds/removes sender from block list.
- SupergroupMembersFilterAdministrators: Member filter for admins only.
- SupergroupMembersFilterBanned: Member filter for banned members.
- SupergroupMembersFilterRecent: Member filter for recently active/joined members.
- ToggleChatIsMarkedAsUnread: Marks/unmarks chat as unread.
- ToggleChatIsPinned: Pins/unpins chat in a list.
- UnpinChatMessage: Unpins a pinned message.
- UserStatusOffline: Represents offline user status object.

### TDLight Core/Client Methods

- addUpdateHandler: Registers callback handlers for incoming TDLib updates.
- build: Builds a SimpleTelegramClient from configured builder/auth supplier.
- builder: Creates a client builder from factory and TDLib settings.
- close: Gracefully closes client/factory resources.
- create: Creates TDLib settings from API token.
- getMeAsync: Fetches current authorized user (self account info).
- init: Initializes TDLight native runtime.
- send: Sends a TDLib request and returns CompletableFuture response.
- setApplicationVersion: Sets app version metadata for TDLib client identity.
- setDatabaseDirectoryPath: Sets path for TDLib local database files.
- setDeviceModel: Sets device model metadata.
- setDownloadedFilesDirectoryPath: Sets path for downloaded files.
- setEnableStorageOptimizer: Enables/disables TDLib storage optimization.
- setIgnoreFileNames: Controls whether original filenames are ignored.
- setLogMessageHandler: Sets TDLight log callback handler.
- setSystemLanguageCode: Sets system language code metadata.
- setSystemVersion: Sets system version metadata.
- setUseTestDatacenter: Switches TDLib to Telegram test DC when enabled.
- user: Creates user authentication supplier data.
